Instalar o Claude Code

Roda nativo no Windows 10 1809+. Não precisa de Administrador. Descubra em qual shell você está pelo prompt: PS C:\ é PowerShell, C:\ sem o PS é CMD.

PowerShell:

PS> irm https://claude.ai/install.ps1 | iex

CMD:

> curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

Conferir. O claude doctor dá o diagnóstico completo sem abrir sessão; claude sozinho inicia e abre o navegador para login.

$ claude --version   # deve imprimir algo como 2.1.238 (Claude Code)
$ claude doctor      # diagnóstico de instalação e settings
$ claude             # inicia a sessão e faz o login
Instale o Git for Windows junto

É opcional, mas define qual ferramenta de shell você ganha. Sem ele, o Claude Code roda comandos via PowerShell. Com ele, usa o Git Bash e libera a ferramenta Bash completa. Se o Git Bash não for encontrado, aponte o caminho no settings.json:

{ "env": { "CLAUDE_CODE_GIT_BASH_PATH": "C:\\\\Program Files\\\\Git\\\\bin\\\\bash.exe" } }

Comece por aqui

Você provavelmente não precisa reconfigurar nada

Se você fez login no Claude Code com sua conta claude.ai, os conectores que já estão lá — Notion, Gmail, Drive, Figma, Adobe, Calendar — aparecem no terminal automaticamente. Não existe comando para adicionar: eles já estão. Rode /mcp dentro do Claude Code e confira antes de sair digitando.

Adicionar um servidor

Toda a decisão está em uma pergunta: o servidor roda na nuvem ou na sua máquina? Se as instruções te derem uma URL, é remoto. Se derem um comando de execução, é local.

Remoto — HTTP

O caso mais comum hoje. Endpoints que terminam em /mcp.

# sintaxe
$ claude mcp add --transport http <nome> <url>

# exemplo real
$ claude mcp add --transport http notion https://mcp.notion.com/mcp

Com token no cabeçalho, quando o serviço não usa OAuth.

$ claude mcp add --transport http minha-api https://api.exemplo.com/mcp \
    --header "Authorization: Bearer SEU_TOKEN"

Remoto — SSE

Alguns serviços ainda só expõem SSE. Mesma estrutura, outro transporte.

$ claude mcp add --transport sse asana https://mcp.asana.com/sse

Local — stdio

Roda um processo na sua máquina. Tudo depois do -- é o comando do servidor, passado intacto.

# sintaxe
$ claude mcp add [opções] <nome> -- <comando> [args...]

# exemplo real
$ claude mcp add --transport stdio airtable \
    --env AIRTABLE_API_KEY=SUA_CHAVE \
    -- npx -y airtable-mcp-server
Por que o traço duplo importa

O -- separa as opções do Claude das opções do servidor. Sem ele, uma flag como --port 8080 no fim da linha seria interpretada como flag do próprio claude mcp add, e o comando quebra.

A partir de um JSON

Quando a documentação do serviço só te dá um bloco mcpServers escrito para outro cliente. Passe o objeto de dentro do bloco, não o bloco inteiro.

$ claude mcp add-json exemplo \
    '{"command":"npx","args":["-y","@exemplo/mcp-server"]}'
O erro que pega todo mundo

Uma entrada com url mas sem type falha. O Claude Code lê qualquer entrada sem type como servidor stdio, então acrescente "type": "http" (ou "sse", ou "ws") antes de colar. Nomes de servidor aceitam só letras, números, hífen e underscore.

Onde a configuração é gravada

Todo claude mcp add grava em escopo local por padrão — ou seja, só naquele projeto. Se você quer o servidor em qualquer pasta, precisa dizer.

EscopoFlagOnde viveQuando usar
local
padrão		 --scope local ~/.claude.json, na entrada do projeto atual Um servidor que só faz sentido neste projeto
project --scope project .mcp.json na raiz do projeto Compartilhar com o time — este arquivo vai pro Git
user --scope user Sua config global Vale em todos os projetos. É o que você quer na maioria dos casos.

Disponível em qualquer pasta da máquina:

$ claude mcp add --transport http --scope user \
    hubspot https://mcp.hubspot.com/anthropic

GitHub

Não existe conector oficial do GitHub no diretório da Claude, então no terminal ele entra na mão, com um token pessoal.

Gere um PAT em github.com/settings/tokens e troque no lugar do placeholder.

$ claude mcp add --transport http --scope user github \
    https://api.githubcopilot.com/mcp/ \
    --header "Authorization: Bearer SEU_GITHUB_PAT"
O comando aceita qualquer coisa

O claude mcp add grava a configuração sem validar a credencial. Um token errado é aceito na hora e só falha depois, na conexão. Confirme com /mcp ou claude mcp get github — se aparecer ✘ com 401, o problema é o token.

Cuidado ao colar tokens

Colar um token com quebra de linha no fim deixa espaço invisível na config. O Claude Code avisa com Leading or trailing whitespace in: headers.Authorization — mas não corrige sozinho. Edite a config para tirar.

Gerenciar o que já existe

Detalhes de um servidor — transporte, escopo, estado e a linha Issue: quando algo falha.

$ claude mcp get notion

Remover. Útil também para refazer um servidor: adicionar o mesmo nome no mesmo escopo dá erro de already exists.

$ claude mcp remove notion

Importar o que já estava configurado no Claude Desktop.

$ claude mcp add-from-claude-desktop --scope user
Não funciona no Windows nativo

O add-from-claude-desktop só roda em macOS e WSL. No PowerShell ou CMD do Windows ele não acha o arquivo de configuração do Desktop — nesse caso, abra o claude_desktop_config.json e refaça as entradas com claude mcp add-json.
