01 · o essencial

O que é uma variável

Uma variável é um nome que aponta para um valor guardado na memória do computador. Ela funciona como uma etiqueta: em vez de repetir o valor toda hora, você usa o nome.

trecho do seu código
NOME_BANCO = "usuarios.db"

Aqui, NOME_BANCO é a variável e "usuarios.db" é o valor (uma string, isto é, um texto). Sempre que o código precisar do nome do arquivo do banco, ele usa NOME_BANCO em vez de escrever "usuarios.db" de novo — se um dia você mudar o nome do arquivo, muda em um lugar só.

CONVENÇÃO

Variáveis em MAIÚSCULAS, como NOME_BANCO, sinalizam por convenção que o valor é uma constante: algo que não deveria mudar durante a execução do programa. Python não impede a alteração — é um combinado entre programadores.

Dentro das funções aparecem outras variáveis: email, senha, conexao, cursor, hash_da_senha. Cada uma guarda um valor diferente — texto, número, ou até um objeto (explicado mais abaixo) — e o nome escolhido deveria sempre descrever o que está guardado ali, como o próprio código faz.

02 · o essencial

Função vs. Método — qual é a diferença?

Essa é a dúvida mais comum de quem está começando, e o seu código tem os dois lado a lado.

Função

Um bloco de código reutilizável, definido com def, que existe "sozinho" e é chamado pelo próprio nome.

def gerar_hash(senha, algoritmo="sha256"):
    ...
    return hash_gerado.hexdigest()

gerar_hash(senha) — chamada direta pelo nome.

Método

Também é uma função — mas uma que pertence a um objeto. Você a chama "grudada" no objeto, com um ponto .

senha_em_bytes = senha.encode("utf-8")
hash_gerado.hexdigest()
cursor.execute(...)

objeto.metodo() — o objeto vem antes do ponto.

Em outras palavras: toda chamada com um ponto na frente é um método (senha.encode(...), conexao.commit(), conexao.close(), cursor.execute(...), email.strip()). Toda chamada sem objeto na frente é uma função (gerar_hash(...), print(...), len(senha), input(...)).

POR QUE ISSO IMPORTA

Método é a forma como orientação a objetos organiza comportamento: um sqlite3.connect(...) devolve um objeto de conexão, e esse objeto já vem com ações prontas — .cursor(), .commit(), .close() — porque foram programadas dentro da classe Connection da biblioteca sqlite3. Você não precisou escrever essas ações: elas já existiam no objeto.

03 · leitura guiada

O código, parte por parte

Agora sim: vamos passar pelo seu programa de cima a baixo, e cada termo novo ganha uma explicação no momento em que aparece.

1. O cabeçalho e os imports

topo do arquivo
"""
Trabalho de Segurança - Hash e senhas em banco de dados
...
"""

import sqlite3
import hashlib
import re
docstring

Texto entre """

Um comentário de várias linhas, geralmente usado para explicar o que o arquivo, a função ou a classe faz. Python o ignora ao executar, mas ferramentas de documentação conseguem lê-lo.

módulo

import

Traz para o seu programa um "pacote de funções prontas" escrito por outra pessoa. sqlite3 lida com banco de dados, hashlib gera hashes, re trabalha com expressões regulares.

comentário

Linhas com #

Tudo depois do # na mesma linha é ignorado pelo Python. Serve só para o ser humano entender o código.

2. criar_banco() — a primeira função

def criar_banco():
    conexao = sqlite3.connect(NOME_BANCO)
    cursor = conexao.cursor()

    cursor.execute("""
        CREATE TABLE IF NOT EXISTS usuarios (
            email TEXT PRIMARY KEY,
            hash_senha TEXT NOT NULL
        )
    """)

    conexao.commit()
    conexao.close()

Uma função é definida com def nome():. O corpo dela — tudo que vem indentado embaixo — só roda quando alguém a chama em outro lugar do código, com criar_banco().

  • sqlite3.connect(NOME_BANCO) — função do módulo sqlite3 que abre (ou cria) o arquivo de banco de dados e devolve um objeto de conexão, guardado na variável conexao.
  • conexao.cursor() — método do objeto conexao. O cursor é o objeto que de fato envia comandos SQL e lê resultados.
  • cursor.execute("...") — método que executa um comando SQL, aqui escrito como uma string de várias linhas.
  • conexao.commit() — confirma (grava de fato) as mudanças no banco.
  • conexao.close() — encerra a conexão, liberando o arquivo.
PONTO DE ATENÇÃO

O comando dentro do cursor.execute(...) no seu arquivo está escrito parte em português — "Criando tabela se ela não existir usuarios (" — em vez do comando SQL real CREATE TABLE IF NOT EXISTS usuarios (. SQL não entende português: isso vai gerar um erro de sintaxe ao rodar. Acima mostrei a versão corrigida, que é a que o comentário do próprio código já descreve como intenção.

3. gerar_hash() — parâmetros e valor padrão

def gerar_hash(senha, algoritmo="sha256"):
    senha_em_bytes = senha.encode("utf-8")

    if algoritmo == "md5":
        hash_gerado = hashlib.md5(senha_em_bytes)
    elif algoritmo == "sha1":
        hash_gerado = hashlib.sha1(senha_em_bytes)
    elif algoritmo == "sha512":
        hash_gerado = hashlib.sha512(senha_em_bytes)
    else:
        hash_gerado = hashlib.sha256(senha_em_bytes)

    return hash_gerado.hexdigest()
  • Parâmetros: senha e algoritmo são os "espaços em branco" que a função espera receber quando é chamada. Quem chama a função fornece os argumentos — os valores reais que preenchem esses espaços.
  • Valor padrão: algoritmo="sha256" significa que, se quem chamar a função não informar o algoritmo, o Python usa "sha256" automaticamente. Por isso gerar_hash(senha) funciona sem o segundo argumento.
  • senha.encode("utf-8") — método de string que transforma texto em bytes (a forma binária que as funções de hash exigem). "utf-8" é a codificação de caracteres, importante aqui porque a senha pode ter acentos.
  • Estrutura condicional if / elif / else — testa condições em sequência. Só o primeiro bloco cuja condição for verdadeira é executado; se nenhuma bater, cai no else.
  • == é o operador de comparação de igualdade (diferente de =, que é atribuição de valor a uma variável).
  • hashlib.sha256(...), hashlib.md5(...) etc. são funções do módulo hashlib que devolvem um objeto de hash.
  • .hexdigest() — método desse objeto de hash, que converte o resultado binário em uma string de letras e números (hexadecimal), pronta para guardar no banco.
  • return — encerra a função e devolve um valor para quem a chamou.

4. senha_e_valida() — booleanos e expressões regulares

def senha_e_valida(senha):
    if len(senha) <= 8:
        print("-> A senha precisa ter de 8 a 16 caracteres.")
        return False

    tem_maiuscula = re.search(r"[A-Z]", senha)
    tem_minuscula = re.search(r"[a-z]", senha)
    tem_especial  = re.search(r"[^A-Za-z0-9]", senha)

    if not tem_maiuscula:
        return False
    if not tem_minuscula:
        return False
    if not tem_especial:
        return False

    return True
  • len(senha) — função embutida do Python que devolve o tamanho (quantidade de caracteres) de um texto.
  • Booleano (bool) — tipo de dado com apenas dois valores possíveis: True (verdadeiro) ou False (falso). Toda a função devolve um booleano, respondendo "essa senha é válida? sim ou não".
  • re.search(padrão, texto) — função do módulo re (expressões regulares) que procura um padrão dentro de um texto. Devolve algo "verdadeiro" se encontrar, e None se não encontrar.
  • Expressão regular (regex) — uma mini-linguagem para descrever padrões de texto: [A-Z] significa "qualquer letra maiúscula", [a-z] "qualquer letra minúscula", e [^A-Za-z0-9] significa "qualquer caractere que não seja letra nem número" — ou seja, um caractere especial. O r antes das aspas (r"...") marca uma raw string, que evita que o Python interprete a barra invertida de forma especial.
  • not — operador lógico que inverte um valor booleano: not tem_maiuscula lê-se "se não tem maiúscula".
PONTO DE ATENÇÃO

A regra pede senha de 8 a 16 caracteres, mas len(senha) <= 8 rejeita também uma senha de exatamente 8 caracteres — o correto seria < 8. Além disso, não existe nenhuma checagem para o limite máximo de 16 caracteres.

5. cadastrar_senha() — laço de repetição e tratamento de erro

def cadastrar_senha():
    email = input("Digite o e-mail: ").strip()

    while True:
        senha = input("Digite uma senha...")
        if senha_e_valida(senha):
            break

    hash_da_senha = gerar_hash(senha, algoritmo="sha256")

    conexao = sqlite3.connect(NOME_BANCO)
    cursor = conexao.cursor()

    try:
        cursor.execute(
            "INSERT INTO usuarios (email, hash_senha) VALUES (?, ?)",
            (email, hash_da_senha)
        )
        conexao.commit()
    except sqlite3.IntegrityError:
        print("-> Esse e-mail já está cadastrado!")

    conexao.close()
  • input(...) — função embutida que pausa o programa, mostra uma mensagem e espera o usuário digitar algo, devolvendo sempre uma string.
  • .strip() — método de string que remove espaços em branco do começo e do fim do texto.
  • Laço de repetição while True: — repete o bloco indefinidamente. Aqui, cria um "loop infinito de propósito", que só é interrompido pelo break lá dentro, quando a senha finalmente é válida.
  • break — sai imediatamente do laço em que está.
  • Tupla (email, hash_da_senha) — uma coleção de valores agrupados entre parênteses, nessa ordem. É usada para preencher os dois ? do comando SQL, um de cada vez.
  • Parâmetros SQL (?) — em vez de colar o e-mail e o hash diretamente dentro da string SQL, o código usa ? como espaço reservado e passa os valores separadamente. Essa é a forma correta e seria mais insegura se fosse feita com f-string, pois abriria brecha para SQL Injection.
  • Tratamento de exceção try / except — tenta executar um bloco de código; se der um erro específico (aqui, sqlite3.IntegrityError, disparado quando o e-mail já existe por ser PRIMARY KEY), o programa não trava — ele executa o bloco except em vez de encerrar com um erro.

6. validar_senha() e pesquisar_hash()

cursor.execute("SELECT hash_senha FROM usuarios WHERE email = ?", (email,))
resultado = cursor.fetchone()

if resultado is None:
    print("-> E-mail inexistente.")
    return

hash_salvo_no_banco = resultado[0]
  • .fetchone() — método do cursor que devolve a primeira linha encontrada pela consulta, ou None se não achar nada.
  • None — um valor especial em Python que representa "nenhum valor" ou "ausência de valor". Comparar com is None (em vez de == None) é a forma recomendada.
  • Indexação resultado[0] — como o resultado do banco vem como uma tupla (mesmo com uma coluna só), o [0] pega o primeiro item dessa tupla.
  • f-string — aparece em print(f"Hash da senha cadastrada: {resultado[0]}"). O f antes das aspas permite colocar variáveis diretamente dentro do texto, entre chaves { }, sem precisar concatenar com +.

7. menu() e o ponto de entrada

def menu():
    criar_banco()
    while True:
        opcao = input("Escolha uma opção: ").strip()
        if opcao == "1":
            cadastrar_senha()
        elif opcao == "4":
            break

if __name__ == "__main__":
    menu()
  • menu() chama as outras funções pelo nome — isso é a essência de organizar um programa em funções: cada uma resolve uma parte pequena, e uma função "maestro" as conecta.
  • if __name__ == "__main__": — um bloco condicional padrão em Python. __name__ é uma variável especial que o próprio Python preenche: ela vale "__main__" quando o arquivo é executado diretamente, e outro valor quando o arquivo é apenas importado por outro programa. Esse teste garante que menu() só roda quando você executa este arquivo, não quando outro script importa suas funções.
04 · referência rápida

Glossário — todos os termos usados

variável
Nome que guarda um valor na memória, para reutilizá-lo depois (NOME_BANCO, senha).
função
Bloco de código reutilizável, definido com def e chamado pelo próprio nome (gerar_hash()).
método
Uma função que pertence a um objeto e é chamada com um ponto (senha.encode()).
parâmetro / argumento
Parâmetro é o nome esperado na definição da função; argumento é o valor real enviado na chamada.
valor padrão
Valor usado automaticamente quando um argumento não é informado (algoritmo="sha256").
return
Palavra-chave que encerra a função e devolve um valor para quem a chamou.
módulo
Arquivo (ou pacote) de código pronto que se traz para o programa com import.
objeto
Um "pacote" de dados e comportamentos (métodos) juntos — como a conexão devolvida por sqlite3.connect().
string (str)
Tipo de dado para texto, sempre entre aspas: "usuarios.db".
bytes
Representação binária de dados, exigida pelas funções de hash. Obtida com .encode().
booleano (bool)
Tipo de dado com apenas dois valores: True ou False.
None
Valor especial que representa "nenhum valor".
tupla
Coleção ordenada e fixa de valores entre parênteses: (email, hash_da_senha).
condicional (if/elif/else)
Estrutura que executa um bloco de código só se uma condição for verdadeira.
laço de repetição (while)
Repete um bloco de código enquanto uma condição for verdadeira — ou, com while True, até um break explícito.
break
Interrompe imediatamente o laço em que está.
try / except
Tenta executar um bloco; se um erro específico acontecer, executa outro bloco em vez de travar o programa.
docstring
Texto entre """ usado para documentar um arquivo, função ou classe.
comentário
Texto após #, ignorado pelo Python, escrito para humanos entenderem o código.
f-string
String com prefixo f que permite inserir variáveis dentro de { }.
raw string
String com prefixo r, usada em regex para evitar interpretação especial da barra invertida.
expressão regular (regex)
Padrão de texto usado para buscar ou validar formatos, via módulo re.
indexação
Acessar um item de uma sequência pela posição, começando em 0: resultado[0].
hash
Resultado de uma função matemática de mão única que transforma qualquer texto em uma sequência fixa de caracteres, praticamente impossível de reverter.
chave primária
Coluna de uma tabela SQL que não pode se repetir e identifica cada linha (aqui, email).
__name__ == "__main__"
Bloco condicional padrão que garante que certo código só rode quando o arquivo é executado diretamente.
