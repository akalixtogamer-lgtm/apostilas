Módulo 01

Fundamentos de UI e Acessibilidade

Antes de abrir o Figma, é preciso entender as regras do jogo. A interface é a ponte entre o sistema e o ser humano — e essa ponte precisa funcionar para todo mundo.

1.1 · A mentalidade Mobile-First

Desenhar Mobile-First significa começar pela menor tela (o celular) e, progressivamente, adaptar para telas maiores. Por quê? Porque o espaço limitado te obriga a priorizar o conteúdo: o que é realmente importante quando não cabe tudo?

No mobile, o dedo é o cursor. O alvo de toque mínimo é de 48×48px (Material Design / Android) ou 44×44px (iOS). Nunca crie áreas clicáveis menores que isso.

O ícone pode ser pequeno (24px), mas a área clicável invisível ao redor dele precisa respeitar os 48px. É isso que separa um toque preciso de um toque irritante.

1.2 · Acessibilidade visual e contraste (WCAG)

Uma interface de qualidade é utilizável por todos. A diretriz WCAG exige contraste mínimo de 4.5:1 para texto normal e 3:1 para texto grande. Use a hierarquia visual (peso e tamanho de fonte) para guiar os olhos: o H1 deve ser, sem dúvida, o elemento mais importante.

Módulo 02

Estrutura, Grid de 8pt e Espaçamento

O segredo de um design profissional (e fácil de codar com frameworks CSS) não está nas cores — está na matemática do espaço.

2.1 · O sistema de Grid de 8pt

No 8pt Grid System, todos os espaçamentos, margens, paddings e dimensões são múltiplos de 8: 8, 16, 24, 32, 40, 48, 56, 64…

Por que o 8? A maioria das resoluções modernas é divisível por 8. Ao exportar assets em 1.5×, 2× ou 3× (telas Retina), múltiplos de 8 escalam em pixels inteiros, evitando o sub-pixel rendering (bordas embaçadas).

  • Exceção — Grid de 4pt: para ajustes finos, como a distância entre um ícone e o texto de um botão, use múltiplos de 4 (4, 12, 20).
Demo · Grid de 8pt ao vivo
gap 16px

Repare: o gap só anda de 8 em 8. Os blocos sempre encostam nas linhas da grade — é assim que o ritmo se mantém perfeito.

2.2 · Alinhamento e ritmo vertical

Alinhar elementos é lidar com dois conceitos que você já conhece da estilização web:

  • Padding (espaçamento interno): entre o conteúdo e a borda do recipiente. Ex.: padding: 16px 24px.
  • Margin (espaçamento externo): entre um recipiente e outro. Ex.: gap de 32px entre o cabeçalho e o primeiro parágrafo.
  • Ritmo: se um título usa 24px de margem inferior, todos os títulos iguais devem respeitar isso. Consistência cria conforto visual.
Módulo 03

Componentes Essenciais e Complexos

3.1 · O Menu Sanduíche (Hamburger)

As três linhas (≡) viraram o padrão universal para ocultar navegação em telas pequenas. Boas práticas:

  1. Evite no desktop: com espaço sobrando, mostre as opções. Esconder navegação aumenta o custo cognitivo.
  2. Animação importa: a transição (overlay ou slide lateral) deve ser suave — algo entre 200ms e 300ms.
  3. Hitbox generosa: o ícone pode ter 24px, mas a área clicável deve ter no mínimo 48×48px.
  4. Acessibilidade: com o menu aberto, prenda o foco dentro dele (trap focus) e permita fechar tocando fora ou num (X) claro.

3.2 · Carrosséis (Sliders)

Carrosséis economizam espaço vertical (ótimo no mobile), permitindo scroll horizontal de cards, imagens ou produtos. Boas práticas:

  1. Dica visual (affordance): nunca esconda totalmente o próximo item. Mostre sempre uma "fatia" (10% a 20%) do próximo card cortado na borda — isso convida ao gesto de swipe.
  2. Controles: no desktop, setas visíveis; no mobile, o gesto basta, mas indicadores (bolinhas) ajudam a entender a quantidade.
  3. Evite auto-play em textos: se há algo para ler, não gire sozinho — isso frustra.

Módulo 04

Dominando o Figma para UI

O Figma não é só uma prancheta — ele funciona com lógicas muito próximas do front-end. Dominando as ferramentas abaixo, seu layout já sai 80% pronto para o código.

4.1 · Configurando o ambiente

  1. Pressione F para selecionar a ferramenta Frame.
  2. Na lateral direita, escolha iPhone 14/15 Pro (393×852) para começar Mobile-First.
  3. Para desktop, depois crie um frame Desktop (1440×1024).

4.2 · Auto Layout (o coração do Figma)

O Auto Layout é a representação visual do Flexbox. Ele controla como os itens se alinham, distribuem espaço e reagem a mudanças de tamanho.

⌨️ Aplicando o 8pt no Auto Layout
  • Selecione os elementos e pressione Shift + A.
  • No painel direito, defina o Gap para valores como 8, 16, 24.
  • Defina o Padding (horizontal e vertical) na mesma escala: 16 nas laterais, 24 em cima/baixo.
  • Vantagem: ao inserir um item no meio, tudo é empurrado automaticamente, preservando o grid.

4.3 · Criando Componentes (Design Systems)

Componentes são elementos reutilizáveis. Um botão principal deve ser componente: muda a cor dele, muda no projeto todo.

  • Atalho: Ctrl + Alt + K (Win) ou Cmd + Opt + K (Mac).
  • Variantes: crie variações do mesmo componente — Botão Default, Hover, Disabled.

4.4 · Prototipando no Figma

É na aba Prototype (canto superior direito) que a interface ganha vida.

≡ Prototipar o Menu Sanduíche
  1. Crie o Frame da tela principal com o ícone (≡).
  2. Crie um segundo Frame: o menu aberto (ex.: barra lateral em 80% da tela).
  3. Na aba Prototype, arraste o "nó" do ícone (≡) até o Frame do menu.
  4. Configure a interação:
    • Trigger: On Click
    • Action: Open Overlay (aparece por cima sem sair da tela)
    • Overlay Position: Top Left / Right
    • Animation: Move In (esquerda ou direita)
    • Marque "Close when clicking outside" — acessibilidade!
↔ Prototipar um Carrossel (Horizontal Scroll)
  1. Agrupe (ou coloque em Auto Layout) todos os cards do carrossel.
  2. Coloque esse grupo dentro de um Frame com a largura da tela do celular.
  3. Marque "Clip Content" no frame para esconder o que passa da borda.
  4. Na aba Prototype, selecione o Frame, vá em Overflow Scrolling e mude para Horizontal. No preview (Shift + Space), já dá pra deslizar!

Leituras para Especialização

Para consolidar a transição ao nível Pleno/Sênior, estas obras formam a base teórica que separa executores de estrategistas.

01

Refactoring UI

Adam Wathan & Steve Schoger

O livro definitivo para devs e iniciantes. Táticas práticas sobre espaçamento, grid e tipografia, sem "teoria acadêmica". Muda sua visão de interface.

02

Don't Make Me Think, Revisited

Steve Krug

A bíblia da usabilidade. Como projetar interfaces intuitivas (menus, navegação) reduzindo a carga cognitiva do usuário.

03

Laws of UX

Jon Yablonski

Princípios psicológicos que ditam como agrupamos informação, o tamanho dos botões (Lei de Fitts) e como organizar carrosséis.

04

The Design of Everyday Things

Don Norman

Clássico sobre por que algumas coisas são fáceis de usar e outras não. Fundamental para entender affordance.
