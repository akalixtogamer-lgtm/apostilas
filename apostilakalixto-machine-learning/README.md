# Machine Learning do Zero · dev-Kalixto

Curso completo de Inteligência Artificial, Machine Learning e Deep Learning, do zero ao intermediário.

- Fundamentos, matemática essencial e preparação de dados
- Tipos de aprendizado e 20 algoritmos e técnicas (regressão, k-NN, Naive Bayes, árvores, Random Forest, boosting, SVM, K-Means, PCA, Label Spreading, Q-Learning)
- Redes neurais do zero (gradiente descendente e retropropagação com NumPy), MLP, CNN, RNN/LSTM, Transformer e modelos de linguagem
- Avaliação honesta: validação cruzada, vazamento de dados, overfitting, métricas e ajuste de hiperparâmetros
- Produção (API com FastAPI) e IA responsável
- 25 exemplos em Python executados com scikit-learn 1.9.1 (a saída mostrada é a real), 24 ilustrações, projeto final, desafios e glossário
- 51 referências em ABNT, marcadas no texto

Quiz de fixação: https://akalixtogamer-lgtm.github.io/quizestudos/quizkalixto-machine-learning/

Baseado numa série de anotações sobre Machine Learning, validada e expandida por Kalixto by Wallace Toledo.
