O despertar dos dados e a mente estatística

Base: material de aula do Prof. Clayton Escouper das Chagas — Aula 01.

Objetivos da aula

  • Entender o que é Estatística e para que um profissional de TI a usa.
  • Diferenciar Estatística Descritiva de Estatística Indutiva (Inferencial).
  • Diferenciar população de amostra.
  • Conhecer as etapas do método estatístico.
  • Rodar seu primeiro describe() no Pandas e perceber o efeito de um outlier.

Por que isso importa para quem programa?

Todo sistema produz dados: logs, tempos de resposta, cliques, erros, vendas. Sem Estatística, a decisão fica no "achismo" ("acho que o servidor está lento"). Com Estatística, a pergunta vira mensurável ("a mediana de latência subiu de 120 ms para 180 ms depois do deploy").

Área Pergunta estatística típica
IA / Machine Learning Qual a probabilidade de este e-mail ser spam?
Performance Meu código ficou mais rápido ou foi sorte nessa execução?
Testes A/B O botão verde converte de verdade mais que o azul?
Recomendação Quem assistiu X tende a assistir Y?

Conceitos

1. O que é Estatística

Estatística é a ciência de coletar, organizar, resumir, analisar e interpretar dados para tomar decisões sob incerteza.

2. Descritiva × Indutiva

Estatística Descritiva Estatística Indutiva (Inferencial)
O que faz Organiza e resume os dados que você já tem Tira conclusões sobre o todo a partir de uma parte
Ferramentas Tabelas, gráficos, média, mediana, desvio padrão Probabilidade, intervalos de confiança, testes de hipótese
Exemplo em TI Frequência de bugs por módulo no último sprint Estimar a taxa de erro de todos os usuários a partir de 10.000 logs
i

Ponte

a Probabilidade (Aulas 08–09) é a "cola" que liga as duas: ela mede o quanto podemos confiar numa conclusão tirada de uma amostra.

3. População × Amostra

  • População (N): o conjunto completo que queremos entender (todos os 10 milhões de logs).
  • Amostra (n): o subconjunto que realmente analisamos (10.000 logs).
  • Parâmetro: número que descreve a população (ex.: média populacional μ).
  • Estatística: número calculado na amostra (ex.: média amostral x̄). Usamos a estatística para estimar o parâmetro.
!

Atenção

O desafio central: a amostra precisa ser representativa. Uma amostra enviesada gera conclusões erradas — não importa quão sofisticada seja a matemática.

4. O método estatístico no dia a dia do dev

  1. Definição — qual pergunta meu código precisa responder?
  2. Coleta — logs, scraping, consultas SQL.
  3. Limpeza (data wrangling) — tratar nulos, tipos errados, duplicados. É onde se passa a maior parte do tempo.
  4. Exposição — tabelas e gráficos que contam a história.
  5. Análise — decidir o próximo passo com base nos números.

Conceitos

1. Classificação de variáveis

Variável
├── Qualitativa (categoria / rótulo)
│   ├── Nominal  → sem ordem   (marca do teclado, SO, método de pagamento)
│   └── Ordinal  → com ordem   (Júnior < Pleno < Sênior, 1★ a 5★)
└── Quantitativa (número que mede ou conta)
    ├── Discreta → contagem    (nº de requisições, carros no estoque)
    └── Contínua → medição     (latência em ms, preço, altura)
i

Regra de ouro

"Faz sentido somar ou tirar média?" Se não faz, a variável é qualitativa — mesmo que seja escrita com números (CEP, ID, CPF, código HTTP).

2. O teste do código HTTP

status = 200, 404, 500 — são números, mas a "média dos status" não significa nada. Status HTTP é qualitativa nominal. Por isso no slide o status aparece como texto ('200').

3. Escalas de medida (acréscimo ao material)

Uma forma mais fina de classificar, muito cobrada em provas:

Escala Operações válidas Exemplo
Nominal = , ≠ SO, cor
Ordinal + ordem (<, >) prioridade, escolaridade
Intervalar + diferenças (sem zero absoluto) temperatura em °C, ano
Razão + razões (zero absoluto) latência, preço, peso
i

Dica do professor

"30 °C não é o dobro de 15 °C" (zero é arbitrário), mas "200 ms é o dobro de 100 ms".

4. População, amostra e erro amostral

  • Erro amostral = diferença entre o valor calculado na amostra (x̄) e o valor real da população (μ).
  • É inevitável porque cada amostra sorteada contém elementos diferentes. Pode ser reduzido aumentando n e usando boas técnicas de amostragem (Aula 03).
  • Não confunda com viés (erro sistemático): o viés não diminui aumentando a amostra.

5. Por que amostrar?

  • Custo computacional — processar 1 PB de logs é caro.
  • Agilidade — decisões não podem esperar dias.
  • Testes destrutivos — testar a durabilidade de todos os SSDs destrói o lote.

Estratégias de amostragem

Base: material de aula do Prof. Clayton Escouper das Chagas — Aula 03.

Objetivos da aula

  • Reconhecer o vício (viés) de seleção.
  • Aplicar amostragem aleatória simples, estratificada, sistemática e conhecer a por conglomerados.
  • Saber quando se usa amostragem não probabilística (conveniência, quotas) e seus riscos.
  • Implementar com df.sample, train_test_split(stratify=...), np.arange + iloc.
  • Garantir reprodutibilidade com random_state.

Conceitos

1. Vício de seleção (bias)

Acontece quando a amostra não representa a população. Exemplo: testar um app só em computadores de última geração → "funciona no laboratório, quebra na vida real".

Outros vieses que aparecem em TI:

  • Viés de sobrevivência — analisar só os servidores que "sobreviveram" e ignorar os que caíram e foram desligados.
  • Viés de não resposta — só quem está muito satisfeito (ou muito irritado) responde a pesquisa.
  • Viés temporal — coletar logs só de madrugada e concluir sobre o dia todo.

2. Técnicas probabilísticas (todo elemento tem chance conhecida de ser sorteado)

Técnica Como funciona Quando usar
Aleatória simples sorteio puro, todos com a mesma chance população homogênea
Estratificada divide em estratos e sorteia proporcionalmente em cada um grupos com comportamento diferente; minorias importantes
Sistemática começa num ponto aleatório e pega 1 a cada k listas/fluxos ordenados (pacotes, logs)
Por conglomerados (acréscimo) sorteia grupos inteiros (ex.: 5 data centers) e analisa tudo dentro deles quando listar todos os elementos é caro

Salto da sistemática:

k = N / n = tamanho da população ÷ tamanho da amostra
!

Cuidado com periodicidade

se o log tem um padrão que se repete a cada 20 linhas (ex.: um job agendado) e você usa k = 20, pode pegar sempre o mesmo tipo de evento. Sorteie o ponto inicial e desconfie de dados cíclicos.

3. Estratificada — tamanho de cada estrato

Alocação proporcional: nᵢ = n × (Nᵢ / N).
Ex.: frota com 60% Etios, 25% Kicks, 15% T-Cross e amostra de 40 → 24, 10 e 6.

4. Não probabilísticas

  • Conveniência: os dados mais fáceis (quem está perto, o servidor mais próximo).
  • Quotas: quantidades fixas por grupo, mas escolhidas pelo pesquisador.
  • Risco: subjetividade → viés. Use só quando o rigor não é crítico (protótipo, sondagem rápida).

Nota do professor

no slide, train_test_split(df, test_size=0.2, ...) devolve 80% na primeira variável. Para pegar a amostra de 20%, use train_size=0.2 (como acima) ou fique com a segunda saída.

Seed / random_state

O computador gera números pseudoaleatórios. Fixar a semente faz o "sorteio" ser o mesmo em toda execução — essencial para que outra pessoa reproduza sua análise. 42 é só convenção (referência ao Guia do Mochileiro das Galáxias).

Distribuição de frequências

Base: material de aula do Prof. Clayton Escouper das Chagas — Aula 04.

Objetivos da aula

  • Transformar dados brutos (rol) em tabelas de frequência.
  • Calcular frequência absoluta (fᵢ), relativa (frᵢ), percentual e acumulada (Fᵢ).
  • Agrupar variáveis contínuas em classes e escolher quantas usar (Regra de Sturges).
  • Usar value_counts, pd.cut e cumsum sem cair na armadilha dos intervalos.

Conceitos

1. Rol

Os dados brutos ordenados. Ordenar já ajuda a ver mínimo, máximo e repetições.

2. Tipos de frequência

Símbolo Nome Fórmula Pergunta que responde
fᵢ absoluta contagem quantas vezes aparece?
frᵢ relativa fᵢ / n que fração do total?
fᵢ% percentual frᵢ × 100 que porcentagem?
Fᵢ acumulada f₁ + … + fᵢ quantos até aqui?
Frᵢ relativa acumulada Fᵢ / n "80% dos usuários carregam o app em até 3 s"
✓

Checagem rápida

Σfᵢ = n e Σfrᵢ = 1 (100%). A última Fᵢ é sempre n.

3. Distribuição por classes (dados contínuos)

Latências raramente se repetem → agrupamos em faixas.

  • Amplitude total: AT = máx − mín
  • Amplitude de classe: h = AT / k
  • Ponto médio: (limite inferior + limite superior) / 2 — usado como "representante" da classe.

4. Regra de Sturges

k = 1 + 3,322 · log₁₀(n)
n k (arredondado)
10 4
50 7
200 9
10.000 14
i

Dica do professor

É um ponto de partida, não lei. Para amostras muito grandes ou assimétricas, outras regras (Freedman–Diaconis, Scott) funcionam melhor. No NumPy: np.histogram_bin_edges(dados, bins="sturges").

5. Intervalos abertos e fechados — a pegadinha

Convenção do slide: [a, b) — fecha à esquerda, abre à direita.

!

Nota do professor

o pd.cut do Pandas faz o contrário por padrão: (a, b] (right=True). Com as classes 0–25k–50k–75k–100k, um carro com 50.000 km cai na 2ª classe no pd.cut padrão e na 3ª classe pela convenção do slide. Para seguir o slide:
python pd.cut(km, bins=[0, 25_000, 50_000, 75_000, 100_001], right=False)
(o 100_001 garante que 100.000 km entre na última classe).

Hands-on — tabela completa

import pandas as pd
import numpy as np

tempos = [102, 150, 103, 158, 105, 145, 150, 110, 120, 148]
df = pd.DataFrame({"ms": tempos})

df["classe"] = pd.cut(df["ms"], bins=3)

tabela = (df["classe"].value_counts().sort_index()
            .rename_axis("Intervalo").reset_index(name="fi"))
tabela["fr_%"] = (tabela["fi"] / tabela["fi"].sum() * 100).round(1)
tabela["Fi"]   = tabela["fi"].cumsum()
tabela["Fr_%"] = tabela["fr_%"].cumsum()
print(tabela)

Conceitos

1. Por que visualizar?

O Quarteto de Anscombe (1973): quatro conjuntos com praticamente a mesma média, variância, correlação e reta de regressão — mas formatos completamente diferentes quando plotados. A versão moderna é o Datasaurus Dozen (Matejka & Fitzmaurice, 2017): um dinossauro com as mesmas estatísticas de um círculo.

!

Mito ou fato?

O slide cita que "o cérebro processa imagens 60.000 vezes mais rápido que texto". Essa frase circula muito em marketing, mas não há estudo científico conhecido que a sustente. O argumento válido é outro: nossa percepção compara posições e comprimentos muito bem (Cleveland & McGill, 1984), e é isso que um bom gráfico explora. Bom exercício de pensamento crítico: sempre pergunte a fonte do número.

Medidas de posição

Base: material de aula do Prof. Clayton Escouper das Chagas — Aula 06.

Objetivos da aula

  • Calcular média, mediana, moda e média ponderada.
  • Saber qual usar em dados simétricos, assimétricos e categóricos.
  • Entender robustez a outliers.
  • Conhecer quartis e percentis como medidas de posição (acréscimo).

Conceitos

1. Média aritmética

x̄ = Σxᵢ / n

Usa todos os valores → é sensível a outliers. Ótima para dados simétricos.

2. Mediana (Md)

Valor do meio do rol (dados ordenados).

  • n ímpar: posição (n + 1)/2.
  • n par: média dos dois valores centrais, posições n/2 e n/2 + 1.

Exemplo par: 3, 7, 1, 9, 4, 6 → ordenado 1, 3, 4, 6, 7, 9 → (4 + 6)/2 = 5.

3. Moda (Mo)

Valor mais frequente. Pode ser amodal, unimodal, bimodal ou multimodal. Única medida de centro que funciona para qualitativa nominal.

4. Média ponderada

x̄w = Σ(xᵢ · wᵢ) / Σwᵢ

Ex.: nota final, score de hardware, prioridade de tickets.

5. Relação média × mediana × forma

Forma Relação típica Melhor medida
Simétrica média ≈ mediana ≈ moda média
Assimétrica à direita (cauda longa para valores altos: salários, latências) média > mediana mediana
Assimétrica à esquerda (cauda para valores baixos) média < mediana mediana
Categórica — moda

Medidas de dispersão

Base: material de aula do Prof. Clayton Escouper das Chagas — Aula 07.

Objetivos da aula

  • Calcular amplitude, variância, desvio padrão, coeficiente de variação e IQR.
  • Entender a diferença entre fórmula populacional (÷ N) e amostral (÷ n − 1) — e qual o Pandas usa.
  • Aplicar a regra empírica 68–95–99,7 e o escore-z para detectar anomalias.

Conceitos

1. Por que a média não basta

Dois servidores com média de 100 ms: A oscila entre 95 e 105 ms; B oscila entre 10 e 500 ms. Mesma média, experiências opostas. A dispersão mede essa diferença.

2. Amplitude

R = x_max − x_min. Rápida, mas só olha os extremos.

3. Variância e desvio padrão

População (conheço todos os dados):

σ² = Σ(xᵢ − μ)² / N  ·  σ = √σ²

Amostra (estimando a população):

s² = Σ(xᵢ − x̄)² / (n − 1)  ·  s = √s²
!

Nota do professor — importante para o cálculo e para o código

o slide mostra a fórmula com n no denominador (populacional). Mas o Pandas (.std(), .var()) usa n − 1 por padrão (ddof=1), enquanto o NumPy (np.std) usa n (ddof=0). Por isso o mesmo dado dá resultados diferentes nas duas bibliotecas!

Servidor pandas .std() (n−1) .std(ddof=0) (n)
Estável [100,102,98,101,99] 1,58 ms 1,41 ms
Instável [10,200,50,150,90] 76,16 ms 68,12 ms

Por que n − 1? (correção de Bessel) A amostra tende a ficar mais "perto da própria média" do que da média real da população; dividir por n − 1 compensa essa subestimação.

Unidades: variância está em unidade² (ms²); o desvio padrão volta à unidade original (ms).

4. Coeficiente de variação (CV)

CV = s / x̄ × 100%

Compara dispersão entre grupos de escalas diferentes (Etios × Ferrari; ETF A × ETF B). Regra de bolso comum: CV < 15% baixa dispersão; 15–30% média; > 30% alta.

5. IQR — a dispersão robusta (acréscimo)

IQR = Q3 − Q1. Não é afetado por outliers (par da mediana, como o desvio padrão é par da média).

6. Distribuição normal e regra empírica

Faixa % aproximada dos dados
μ ± 1σ 68%
μ ± 2σ 95%
μ ± 3σ 99,7%

Escore-z (acréscimo): quantos desvios um valor está da média.

z = (x − x̄) / s

|z| > 3 → forte candidato a anomalia (vale para dados aproximadamente normais).

Introdução à probabilidade

Base: material de aula do Prof. Clayton Escouper das Chagas — Aula 08.

Objetivos da aula

  • Diferenciar experimento aleatório de determinístico.
  • Definir espaço amostral (S) e evento (E).
  • Calcular probabilidade clássica, complementar, união e interseção.
  • Contar possibilidades com o princípio multiplicativo (acréscimo: permutação e combinação).
  • Entender a Lei dos Grandes Números e fazer uma simulação de Monte Carlo.

Conceitos

1. Aleatório × determinístico

  • Determinístico: mesma entrada → mesma saída (uma função pura, 2 + 2).
  • Aleatório: resultado incerto antes de acontecer (dado, perda de pacote, falha de disco).

2. Espaço amostral e evento

  • S = todos os resultados possíveis. Dado: S = {1, 2, 3, 4, 5, 6}.
  • E ⊂ S = resultados que nos interessam. "Par": E = {2, 4, 6}.

3. Definição clássica (resultados equiprováveis)

P(E) = nº de casos favoráveis / nº de casos possíveis = |E| / |S|
!

Atenção

Só vale se todos os resultados têm a mesma chance. "Chover ou não chover" não é 50%/50%.

Definição frequentista (acréscimo): P(E) ≈ nº de vezes que E ocorreu / nº de repetições — é a ideia por trás da Lei dos Grandes Números e do Monte Carlo.

4. Axiomas / regras de ouro

  1. 0 ≤ P(A) ≤ 1
  2. P(S) = 1
  3. Complementar: P(Aᶜ) = 1 − P(A)
i

Truque do "pelo menos um"

é quase sempre mais fácil calcular pelo complementar.
P(pelo menos 1 de 3 servidores cair) = 1 − P(nenhum cair) = 1 − 0,999³ ≈ 0,30% (se cada um tem 99,9% de disponibilidade e as falhas são independentes).

5. União, interseção e exclusão mútua

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
  • Mutuamente exclusivos: P(A ∩ B) = 0 (status 200 e 404 na mesma requisição).
  • Não confundir com independentes (Aula 09): P(A ∩ B) = P(A)·P(B).

6. Contagem (acréscimo — essencial para P clássica)

Situação Fórmula Exemplo
Princípio multiplicativo n₁ · n₂ · … token de 3 letras A–Z: 26³ = 17.576
Permutação (ordem importa, todos) n! ordenar 5 jobs: 120
Arranjo (ordem importa, escolho k) n!/(n−k)! pódio de 3 entre 10: 720
Combinação (ordem não importa) n!/(k!(n−k)!) escolher 3 de 10 servidores: 120 
from math import comb, perm, factorial
comb(10, 3), perm(10, 3), factorial(5)

7. Lei dos Grandes Números

Quanto mais repetições, mais a frequência observada se aproxima da probabilidade teórica. Não garante que "depois de muitos 5 vai sair um 6" (isso é a falácia do jogador): o dado não tem memória.

8. Monte Carlo

Resolver um problema de probabilidade sorteando milhares/milhões de vezes e contando. Nome e método popularizados por Metropolis & Ulam (1949), a partir de trabalhos em Los Alamos nos anos 1940.

Probabilidade condicional e Teorema de Bayes

Base: material de aula do Prof. Clayton Escouper das Chagas — Aula 09.

Objetivos da aula

  • Diferenciar eventos independentes e dependentes (com o teste matemático).
  • Calcular P(B|A) por fórmula e por tabela de contingência.
  • Usar a regra do produto, a Lei da Probabilidade Total e o Teorema de Bayes.
  • Entender o paradoxo do falso positivo e a ideia de sensibilidade/especificidade.
  • Construir um classificador Naive Bayes simples.

Conceitos

1. Probabilidade condicional

P(B | A) = P(A ∩ B) / P(A), com P(A) > 0

Leitura: "probabilidade de B dado que A ocorreu". Na prática: restringimos o espaço amostral aos casos em que A aconteceu.

2. Regra do produto (acréscimo)

P(A ∩ B) = P(A) · P(B | A)

Baralho sem reposição, 2 ases seguidos: (4/52)·(3/51) ≈ 0,45%.
Com reposição (independentes): (4/52)² ≈ 0,59%.

3. Independência — o teste

A e B são independentes se e somente se

P(A ∩ B) = P(A) · P(B)  ⇔  P(B | A) = P(B)
!

Independente ≠ mutuamente exclusivo.

Se A e B são exclusivos (e ambos possíveis), saber que A ocorreu garante que B não ocorreu — então eles são dependentes!

4. Tabela de contingência (acréscimo — a forma mais fácil de pensar)

Com erro Sem erro Total
Mobile 50 100 150
Desktop 30 20 50
Total 80 120 200
  • P(erro | mobile) = 50/150 ≈ 33,3%
  • P(mobile | erro) = 50/80 = 62,5%
i

Dica do professor

P(A|B) e P(B|A) não são a mesma coisa. Confundi-las é a "falácia da condicional invertida" — o erro que o Bayes corrige.

5. Lei da Probabilidade Total

P(B) = P(B | A)·P(A) + P(B | Aᶜ)·P(Aᶜ)

6. Teorema de Bayes

P(A | B) = P(B | A) · P(A) / P(B)
Termo Nome Significado
P(A) prior (a priori) crença antes da evidência
P(B|A) likelihood (verossimilhança) chance da evidência se A for verdade
P(B) evidência chance total da evidência (prob. total)
P(A|B) posterior (a posteriori) crença atualizada

Posterior de hoje = prior de amanhã. Cada nova evidência atualiza a crença (ex.: segundo exame).

7. Vocabulário de testes (acréscimo)

  • Sensibilidade = P(positivo | doente) — acerta os doentes.
  • Especificidade = P(negativo | saudável) — acerta os saudáveis.
  • Taxa de falso positivo = 1 − especificidade.
  • "Teste 99% preciso" é ambíguo: precisa dizer qual das duas.

O paradoxo do falso positivo

!

Nota do professor (errata)

o slide descreve uma doença de 1 em 10.000 com teste 99% preciso, mas o código usa prevalência de 0,1% (1 em 1.000) e 5% de falso positivo. São dois cenários diferentes — os dois ensinam a mesma coisa:

Cenário Prevalência Sensib. Falso + P(doente | +)
Slide (texto) 0,01% 99% 1% ≈ 0,98%
Slide (código) 0,1% 99% 5% ≈ 1,94%

Por quê? Em 100.000 pessoas (cenário do código): 100 doentes → 99 positivos verdadeiros; 99.900 saudáveis → ~4.995 falsos positivos. Dos ~5.094 positivos, só 99 estão doentes.

def bayes(prior, sens, falso_pos):
    p_evid = sens * prior + falso_pos * (1 - prior)
    return sens * prior / p_evid

p1 = bayes(0.001, 0.99, 0.05)   # 1º teste positivo
p2 = bayes(p1,    0.99, 0.05)   # 2º teste positivo (independente)
print(f"{p1:.2%} → {p2:.2%}")   # 1.94% → 28.18%

def resumo(s: pd.Series) -> dict:
    q1, q3 = s.quantile([.25, .75])
    iqr = q3 - q1
    outliers = s[(s < q1 - 1.5*iqr) | (s > q3 + 1.5*iqr)].tolist()
    return {
        "media": s.mean(), "mediana": s.median(), "desvio": s.std(),
        "cv_%": s.std() / s.mean() * 100, "outliers": outliers,
    }
