Etapa 02

1 Criação do repositório no GitHub

O primeiro passo é criar um repositório remoto. Ele guarda o código-fonte e registra o histórico (versionamento) da aplicação.

  1. Acesse sua conta no GitHub e clique em New repository.
  2. Dê um nome, por exemplo sistema-usuarios.
  3. Escolha público ou privado. Não marque "Add a README": o Angular já cria os arquivos e isso evita conflito no primeiro push.
  4. Clique em Create repository e copie a URL.

4 Criação do componente Cadastro

Como o projeto vai virar um CRUD, o formulário não fica no componente principal. Criamos um componente só para a tela de cadastro.

O comando cria a pasta src/app/cadastro com quatro arquivos. No Angular 20 os nomes ficam mais curtos: sai o sufixo .component e a classe se chama apenas Cadastro.

Etapa 07

6 Chamada do Cadastro no componente App

O componente App é a porta de entrada. Para ele exibir o Cadastro, são dois passos: importar a classe no app.ts e usar o seletor no app.html.

Por que o imports: [Cadastro]? No Angular 20 os componentes são standalone: cada um declara do que precisa. Se você esquecer esse import, o terminal acusa que app-cadastro não é um elemento conhecido.

Etapa 10

9 Componente Lista com @for e @if

Evolução para CRUD

Esta tela mostra os usuários cadastrados e permite excluir. É aqui que aparecem os blocos de controle do template.

BlocoFunção
@if / @elseMostra um trecho só se a condição for verdadeira. Quando é falsa, o trecho nem existe no HTML.
@for (u of usuarios; track u.id)Repete o bloco para cada item. O track é obrigatório e identifica cada item para o Angular atualizar só o que mudou.
@emptyOpcional; aparece quando a lista está vazia.
Sintaxe antiga. Em tutoriais anteriores ao Angular 17 você vai encontrar *ngFor e *ngIf. Fazem o mesmo, mas a sintaxe com @ é a recomendada e não precisa importar nada.

✎ Exercício proposto

  1. Adicione novos campos ao formulário, separados em dois grupos: Endereço (CEP, rua, número, bairro) e Contatos (celular, WhatsApp, Instagram).
  2. Organize os campos em duas colunas com o grid do Bootstrap.
  3. Desafio: exiba os novos campos na tabela da Lista.
Ver um caminho de solução (tente antes!)

O segredo das duas colunas é colocar os campos dentro de uma row e dar a cada um col-md-6: em telas médias e maiores cada campo ocupa metade; no celular, a largura toda.

Lembre de incluir os novos campos também na interface Usuario e no objeto usuario do cadastro.ts.
