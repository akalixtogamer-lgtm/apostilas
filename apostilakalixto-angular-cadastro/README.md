# Angular 20 na prática · dev-Kalixto

Apostila interativa: projeto Angular 20 com Bootstrap, componente Cadastro e evolução para CRUD (service, bindings, lista e rotas).

- `index.html` — apostila com arquitetura clicável (cada etapa abre os códigos)
- `quiz.html` — aba de quiz (12 perguntas)
- `code.js` — todos os códigos exibidos na apostila
- `app.js` / `style.css` — comportamento e identidade visual

Baseado na apostila do Prof. Vitor H. V. Reis (Programação Front-End III, Senac RJ).
